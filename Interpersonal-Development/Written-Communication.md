# Written Communication

## Overview

Clear writing gets ideas across quickly, reduces back-and-forth, and builds professionalism. It applies to email, docs, proposals, and chat—see [Email & Communication Management](../Productivity-Techniques/Email-Communication-Management.md) for inbox and workflow; this note is about how to write clearly.

## Why It Matters for Productivity

- **Less rework** — Clear messages get understood the first time.
- **Faster decisions** — Good docs and emails enable async alignment.
- **Professional image** — Clear writing signals competence and respect for the reader’s time.
- **Record** — Written communication creates a trace for reference and accountability.

## Principles

### Put the Main Point First

- Lead with the conclusion or request (e.g. “I need your approval on X by Friday”).
- Then add context, background, or options.
- Busy readers often only read the first line or two.

### Be Concise

- Short sentences and paragraphs.
- Cut filler (“just,” “actually,” “in order to” when “to” suffices).
- One idea per paragraph when possible.

### Structure for Scanning

- Use headings, bullets, and numbered lists.
- Bold key terms or decisions.
- Break long blocks into short sections.

### Match Tone to Context

- Formal for external or high-stakes; more casual for familiar colleagues when appropriate.
- Avoid sarcasm or ambiguity in writing; tone is easy to misread.
- See [Presentation Skills](./Presentation-Skills.md) and [Storytelling](./Storytelling.md) for verbal tone.

### One Purpose per Message

- One email or section = one main ask or topic when possible.
- Multiple asks = numbered list or separate messages so nothing is missed.

## Common Formats

- **Email** — Subject that states the topic or ask; see [Email & Communication Management](../Productivity-Techniques/Email-Communication-Management.md).
- **Proposals and docs** — Executive summary first; details and appendices after.
- **Meeting notes** — Decisions, action items, owners, and deadlines; see [Meeting Effectiveness](../Productivity-Techniques/Meeting-Effectiveness.md).
- **Chat** — Short and scannable; move complex threads to doc or email when needed.

## Revising

- Read aloud to catch awkward or unclear phrases.
- Cut anything that doesn’t serve the reader.
- Check: “If I knew nothing about this, would I understand?”
